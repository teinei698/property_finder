# AUDIT: Elite Residence, Dubai Marina

**What we checked and list we have:** 38 live listings (27 rent, 11 sale) out of all 442 live listings in one tower (307 rent, 135 sale). The date is on 14 Nov 2026, from propertyfinder.ae, the reange is only at what a person searching can see (search results, listing page, photos, the DLD permit block, the "available from" date).

## Why this building

The search URL I started from was Dubai Marina rentals (`/en/search?c=2&l=50&rp=y`). Elite Residence is the tower with the most listings in Dubai Marina for rent (307) by far and the second most for sale (134). It is a single 91-floor tower with a few standard floor plans. Therefore many honest listings look the same on paper.

## How I checked each listing

| Check | How |
|---|---|
| **Price believable?** | Compared each listing with the median of all live listings in the same tower, same type (rent or sale), same bedrooms and same floor-plan size (±10 sqft). The "group" column lists that median and how many listings it is based on. |
| **Same unit listed more than once?** |  Same photo file appearing in two listings (Property Finder serves each image with a content hash `v=`; equal hash means the same file). Looked at the photos side by side for listings whose hashes differ to catch watermarked photos. |
| **Photos match the building?** | Looked at the first 3 photos of **all 38** listings: view (Palm / Ain Dubai / Marina from a high floor fits this tower), interiors, empty or furnished, and whether they match the text and fields. |
| **Likely still available?** | Listing date and "available from" date. A date months in the past on a listing that says "vacant now" is a warning. |
| **Anything else wrong?** | DLD permit shown or not, licence type, text that contradicts the fields or the photos, payment tricks. |

Here are three validations:
- ✅ **Trust**: nothing found against it.
- ⚠️ **Ask first**: plausible, but the assistant should ask the agent a few specific questions before it goes on the short list. *"Assistant would ask" describes what the product does. No agent was contacted during this audit, which uses only what a person searching can see.*
- ❌ **Hide**: likely bait.

**Copies are never marked as confirmed.** Identical photos do not prove one flat. However in a tower with standard floor plans, an agency can reuse the photos of one unit for a twin unit on another floor. Such listings are marked **highly suspected copy** (⚠️) and only the unit number or floor from the agent can confirm them.

**Dual listings are not copies.** An owner may list the same flat for rent and for sale at the same time through one agent. These are linked to each other for information only.
